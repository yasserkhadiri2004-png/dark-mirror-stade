Installation
============

Prerequis : Python 3.10+, Webcam, Cle API ElevenLabs

Etapes
------

1. Cloner le repo::

    git clone https://github.com/yasserkhadiri2004-png/dark-mirror-stade.git

2. Installer les dependances::

    pip install flask opencv-python numpy requests insightface onnxruntime

3. Lancer::

    python main.py
